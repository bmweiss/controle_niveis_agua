📖 Sobre o Projeto
Sistema simples em Python para simular o monitoramento de um reservatório de água. O programa exibe mensagens coloridas no terminal conforme o nível do reservatório, facilitando a visualização dos alertas.

A cor de cada mensagem é definida por uma função, que escolhe a cor de acordo com o nível.


🎯 Objetivo
Simular 5 níveis de água de um reservatório;

Exibir uma mensagem de alerta para cada nível;

Usar a biblioteca colorama para colorir as mensagens;

Restaurar o estilo padrão do terminal ao final.


📋 Tabela de Níveis
Nível	Situação	Cor
1	Muito baixo (crítico)	🔴 Vermelho
2	Baixo	🟡 Amarelo
3	Médio	🟢 Verde
4	Alto	🔵 Ciano
5	Muito alto (alerta)	🔵 Azul
